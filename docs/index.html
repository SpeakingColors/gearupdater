Studio 87 Gear Updater

One window for every Studio 87 plugin and app: see what has a newer version on GitHub, and update one, several or all. Free and open source.
Test build, version 0.1.2 (pre-release). Version 0.1.0 was tried on Windows by the author and worked. Nothing in 0.1.2 has been tried on a real machine yet, and macOS and Linux have not been tested by anyone. The macOS package is missing from v0.1.2 (the macOS build queue was stuck), so v0.1.2 has Windows and Linux installers only. The installers are not code-signed.
The real window, rendered offscreen with recorded GitHub data. The installed versions are staged so that every state shows.
  • Lists every public Studio 87 product, with search and category tabs, and shows the installed version next to the latest one.
  • Checks GitHub only when you open it or click Check for updates. No timers, no background checks, no auto-start.
  • Collects nothing. Every download is checked against its SHA256 sums first and refused on a mismatch.
  • Keeps the previous plugin version so Roll back is one click. It never touches your presets.
